# CrewAI

## CrewAI has several offerings 

CrewAI Enterprise: A multi-agent platfrom for deploying, running and monitoring Agentic AI
CrewAI UI Studio: A no-code/ lo-code product from creating multi-agent solutions
`CrewAI open-source framework: Orchestreate high performing AI agents with ease and scale`

##3 framework flavors 

`CrewAI Crews: Autonomous solution with AI teams of Agents with different roles`
"Choose Crews when: need autonomous problem-soving, creative collaboration, or exploratroy tasks"

CrewAI flows: Structured automations by dividing complex task into precise workflows
"Chose Flows when: requred deterministic outcomes, auditablity, or precise controle over executoin" 



## Core concepts 

Agent: an autonomous unit, with an LLM, a role, a goal, a backstory, memory, tools

Task: a specific assignments to be carried out, with a description, expected output, agent (task is assigned to agent)

Crew: a team of Agents and Tasks; either:
1. Sequential: run tasks in order they are defined
2. Hierarchical: use a Manager LLM to assign
